# 班主任工作台（banzhuren-app）

一位初中班主任给自己（也给你）做的**班级管理工作台**：学生档案、考勤、作业、值日、成绩分析、评语、打印中心…… 25 个功能模块，手机 / iPad / 电脑三端适配，添加到主屏幕即可当 App 用。

**技术栈**：Next.js 14 (App Router) + TypeScript + Tailwind CSS + ECharts + SheetJS (xlsx)

**数据全部保存在本机浏览器（IndexedDB），不需要注册任何云服务、不需要配置数据库** —— clone 下来装好依赖就能用。

## 🚀 快速开始

```bash
git clone <本仓库>
cd banzhuren-app
npm install
npm run dev          # http://localhost:3000
```

首次打开会进入登录页：

1. **初始化本机账号**：设置一个用户名和密码（只保存在这台设备的浏览器里，用于锁住你的数据）。
2. 创建班级（设置页/首次引导），然后到「导入中心」下载模板、导入学生名单，即可开始使用。

> 想先看看功能？登录页点「演示模式（示例数据）」，无需任何设置。

### 生产构建 / 部署

```bash
npm run build        # 纯静态导出到 out/，任意静态托管（Nginx / 1Panel 静态网站 / GitHub Pages）皆可
npm run preview      # 本地预览 out/
```

Docker：

```bash
docker compose up -d --build   # 映射到宿主机 3100 端口
```

## 🔒 数据与隐私设计

所有学生数据都是敏感个人信息，本项目按「数据不出本机」的思路设计：

| 措施 | 说明 |
|---|---|
| 数据本地化 | 业务数据存 IndexedDB（浏览器本机），附件（学生照片等）也存本机；不上传任何服务器 |
| 本机账号 | 登录口令仅存 PBKDF2-SHA256 哈希，明文密码不落盘；本机登录态防误触，敏感页另有 PIN 锁 |
| 身份证号不入库 | 导入新生调查表时身份证号仅用于提取生日和校验性别，解析后立即丢弃 |
| 问卷系统列不入库 | 序号/提交时间/来源/IP 等平台列自动跳过 |
| 防截图水印 + 应用锁 | 全屏水印可开关；重点关注/安全中心等敏感页支持 PIN 锁 |
| 加密备份 | 安全中心一键导出 AES-GCM 加密 .dshbak；换设备/清浏览器数据靠它恢复（解密后 JSON 可重新导入） |
| 审计日志 | 登录、导入、删除、打印等敏感操作只追加记录，可在安全中心自查 |
| 手机号脱敏 | 打印输出支持一键打码（设置页开关） |

> ⚠️ 提醒：浏览器清理「站点数据」会删除本应用的全部本地数据，请养成每周导出加密备份的习惯（安全中心）。

## 🧱 数据层实现（lib/）

```
lib/supabase.ts    # 数据层门面：getSupabase() / audit()，全站唯一入口（历史命名保留）
lib/local-core.ts  # 本地查询引擎：from/eq/insert/update/delete/upsert/rpc/v_* 视图
lib/local.ts       # 本地持久化：IndexedDB 快照 + 本机账号（PBKDF2）+ 附件存储
lib/demo.ts        # 演示模式：同一引擎 + 内存示例数据
```

`design-docs/` 目录保存了设计文档（功能规格、数据库设计、成绩分析、安全设计），
其中 `design-docs/supabase/schema.sql` 可作为**数据模型参考** —— 开源版本的数据层已改为上述本地实现，不再依赖 Supabase。
