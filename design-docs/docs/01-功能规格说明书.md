# 班主任管理系统 · 功能规格说明书（v1.1）

> 本文档是开发与验收的依据。每个模块给出：目的 / 数据字段 / 操作流程 / 细节与边界 / 打印与导出。
> 约定：所有"学生"操作均可先全局搜索（姓名或学号）定位；所有日期默认今天；所有删除均为软删除（可恢复）。

---

## 0. 通用设计约定

### 0.1 响应式布局
| 断点 | 设备 | 布局策略 |
|---|---|---|
| < 640px | 手机 | 单列卡片、底部导航、大按钮（触控 ≥ 44px）、录入页大字号 |
| 640–1024px | iPad | 双栏、侧边导航收拢、表格中等密度 |
| > 1024px | 笔记本 | 三栏/表格密集模式、键盘快捷键 |

### 0.2 高频录入的通用技巧（全系统贯彻）
- 默认值优先：作业默认"已交"、考勤默认"正常"、日期默认今天——**只点异常项**
- 批量操作：整排标记、多选学生后批量设置
- 粘贴支持：成绩/名单支持从 Excel 复制后整列粘贴
- 模板：学生导入 Excel 模板、评语素材库、考勤节点预设、值日任务预设、班委职位预设
- 快捷入口：今日看板一键进入当日考勤/作业/值日登记

### 0.3 数据约定
- 所有表：`created_at` / `updated_at` 自动维护
- 软删除：`deleted_at` 字段，列表默认过滤；回收站保留 30 天
- 学期标识：`2025秋`、`2026春`（学年 + 季）
- 隐私：手机号列表页默认打码（如 `138****1234`），详情页可展开；导出默认脱敏
- 权限：全系统单用户（owner），RLS 见 schema.sql

## A. 班级与学生（地基）

### A1 班级设置
**目的**：管理你负责的所有班级（班主任班 + 任教班），及每个班的运行参数。

字段：
- 班级名（如"初一（3）班"）、年级（初一/初二/初三）、学年学期
- 班级角色：`班主任` / `任教`（任教班需指定科目，如语文）
- 座位网格：行数、列数（默认 8×7，可调）
- 考勤节点预设（默认：早读、眼操、课间操、午休、晚自习）
- 值日任务预设（默认：扫地、拖地、擦黑板、擦讲台、倒垃圾、走廊、关灯关门）
- 科目清单（班主任班：语文/数学/英语/政治/历史/地理/生物；任教班：语文）
- 任课教师备注（选填）

操作流程：开学时创建班级 → 配置参数 → 导入学生 → 排座 → 分值日组。

细节与边界：
- 学年学期切换：看板与各模块默认按"当前学期"过滤；历史学期只读可查
- 班级支持"归档"（见 G3），归档后所有模块只读

### A2 学生档案
**目的**：学生信息中心，一切模块的数据源；支持从学校学籍表一键导入。

字段：
| 分组 | 字段 |
|---|---|
| 基本信息 | 学号（班内唯一）、姓名、性别、生日、照片（Storage）、住址 |
| 家庭信息 | 监护人1 姓名/关系/电话、监护人2 姓名/关系/电话、家庭结构（双亲/单亲/留守/离异/其他）、接送人 |
| 健康信息 | 过敏史、慢性病、视力听力、特殊情况（如不能跑操/需坐前排） |
| 入学背景 | 毕业小学、入学成绩（摸底）、是否住校 |
| 标记 | 标签（text[]，如"需家访""住校"）、重点关注级别（无/黄/红）、备注 |

操作流程：
- 开学：下载 Excel 模板 → 从学校学籍表粘贴 → 上传导入 → 逐条补全家庭/健康信息
- 日常：新增/编辑/转学（标记 inactive，保留历史）/合并误建档案

细节与边界：
- **照片**：录入或拍摄，存 `photos` 桶（私有），列表缩略图，详情大图
- **隐私**：不录身份证号；手机号列表页打码；详情页展开需点按
- **搜索**：全局搜索支持姓名拼音首字母（如 `lxy` → 李小雨）
- **转学处理**：学生保留档案但标记离班日期；所有历史记录（考勤/成绩/事件）不删除
- **学生详情页**（重点页面）：
  - Tab1 基本信息 | Tab2 考勤汇总 | Tab3 成绩趋势 | Tab4 事件/谈话 | Tab5 家校联系 | Tab6 成长时间线

### A3 智能排座 + 轮换 + 拖拽编辑 + 座位图导出
**目的**：开学排座 + 每周轮换，支持拖拽微调、点击交换，可导出座位图（预览图/PNG/A4）。

**① 拖拽编辑（核心交互）**：
- 桌面端：直接拖拽学生卡片到目标座位（悬停高亮目标格，松手落位）
- iPad/触屏：长按 300ms 拾起 → 拖动 → 松手放置（pointer events + `touch-action:none`，滚动不冲突）
- 小屏手机：降级为"**点选 → 点放**"两段式（拖拽在 6 寸屏上不友好）
- **点击交换**：点学生 A → 点学生 B → 两人互换（快速调同桌）
- **批量移动**：框选/多选多个学生 → 整体拖到新位置（保持相对布局）
- **锁定座位**：🔒 标记，不可拖入、不参与轮换（如近视生固定前排）
- **撤销 / 重做**：操作栈，Ctrl+Z / Ctrl+Shift+Z（触屏：工具栏按钮）
- **自动保存**：拖拽后防抖 2 秒写入 `seats` 表；"保存为快照"显式写 `seat_history`（每次调整留痕）
- 缩放与导航：网格缩放 50%~150%，大班额可滚动；讲台方向标识

**② 规则排座（一键生成）**：可选规则组合：
   - 按身高（从档案"身高"字段或临时录入）
   - 按视力/特殊需求（前排优先）
   - 男女搭配（相邻座异性或同性间隔，可配）
   - 成绩搭配（好带弱，按最近一次成绩）
   - 指定同桌/指定座位（老师手动锁定，规则排座时不动）
   - 隔离名单（如某两人不坐一起）

**③ 每周轮换**：默认"左右换 + 前后换"组合；可设轮换周期（1/2周）；轮换后仍可拖拽微调。

**④ 座位图导出（预览图）**：
1. **实时预览**：编辑页所见即所得（当前网格即预览，无需另开页面）
2. **导出 PNG 图片**：canvas 渲染（2x/3x DPI，适配教室大屏与微信发送）
   - 显示选项：仅姓名 / 姓名+学号 / 带照片 / 性别配色（男蓝女粉，可开关）
   - 讲台标识：网格上方"讲台"横条，文字可自定义
3. **导出 PDF / A4 打印**：与打印中心联动（见 H3）
4. 用途：贴讲台、交年级组、发家长群（可脱敏仅姓名）

**⑤ 历史记录**：每次排座/轮换/快照可回看"第几周谁坐哪"（seat_history）。

细节与边界：
- 规则冲突（如身高排座与指定同桌矛盾）：系统提示冲突项，老师决定优先级
- 座位状态：`occupied` / `empty` / `locked`（锁定座位不参与轮换）
- 未保存的拖拽离开页面时提示"有未保存的调整"
- 技术备注：拖拽用 Pointer Events（鼠标+触屏统一）；导出用 canvas 绘制（不依赖 DOM 截图，保证清晰度与一致性）

## B. 每日事务（高频，效率优先）

### B1 考勤
**目的**：日常考勤 + 请假审批 + 周月汇总 + 交学校。

**打卡模式（双模式并存）**：
- 模式1 **节点考勤**：按节点（早读/眼操/课间操/午休/晚自习）逐项记录
- 模式2 **每日总考勤**：每天每生一个状态（正常/迟到/早退/病假/事假/公假/旷课），最快完成

操作流程（手机端 10 秒/次）：
1. 看板点"今日考勤" → 默认今天、默认全班"正常"
2. 点选异常学生 → 选择状态（迟到可填分钟数）→ 保存
3. 支持"整排快速标记"（如第三组全部迟到）与"整日补录"

请假审批流：
1. 家长来电/微信请假 → 登记请假单（学生、类型：病假/事假/公假、起止日期、原因、是否已联系家长）
2. 批准 → 自动生成该时间段该生的考勤记录（状态=请假类型）
3. 返校销假 → 标记销假，考勤记录保留
4. 拒绝 → 可备注原因（如"请家长到校沟通"）

细节与边界：
- **状态枚举**：`正常/迟到/早退/病假/事假/公假/旷课`；迟到必须填分钟数（统计用）
- 旷课红色高亮；连续 2 次旷课 → 看板提醒"建议联系家长"
- 早读迟到（7:20 后到校）与正课迟到分开统计
- 周月汇总：每生迟到次数、请假天数、旷课次数；班级汇总表（交学校格式）
- 打印：`考勤汇总表`（按月，每生一行，各状态列）

### B2 值日
**目的**：分组轮换 + 每日检查 + 打印值日表。

- 分组：默认 5 组（周一~周五各一组），组员分配（拖拽/自动均分）；可设"周五全员大扫除"
- 任务清单（预设）：扫地、拖地、擦黑板、擦讲台、倒垃圾、走廊、关灯关门、检查饮水机
- 轮换：每周自动轮转（本周 A 组 → 下周 B 组）；值日表自动生成"本周值日表"
- 检查记录：值日生或劳动委员登记检查结果（达标 / 问题+备注，如"黑板未擦净，已重做"）
- 打印：`本周值日表`（组 × 任务 × 学生名单）贴教室

细节与边界：
- 值日记录与事件台账打通：检查不达标可一键转为"事件记录"（类型=其他）
- 请假学生值日自动顺延（可配：自动 or 手动）

### B3 作业收交登记
**目的**：每日收交登记 + 未交催缴 + 连续未交预警。

操作流程（每科 5 秒）：
1. 选日期 + 科目（默认今天，默认全班"已交"）
2. 点选未交学生（可备注原因）→ 保存
3. 顺手标记"优秀作业"（供展示/表扬）

细节与边界：
- **连续未交预警**：一周内未交 ≥ 3 次 → 看板红点 + 建议联系家长
- 汇总：每周每科未交名单（可发家长群，脱敏可配）
- 与课堂工具"随堂速记"联动：课堂上发现未交可直接记录

### B4 课堂工具包（新增，借鉴班级优化大师但去积分）
**目的**：上课随手用的轻量工具，零负担。

1. **随机点名**：全班/当前小组/未点名名单中随机抽 1 人（不重复直到轮完一圈），
   支持"抽 2 人 PK""指定排除名单"；大字号全屏模式适配教室一体机/手机投屏
2. **随堂速记**：一键记录"表扬 / 提醒 / 违纪"，直接写入事件台账（B5），
   可选关联随机点名（如点名回答好 → 表扬）
3. （v2）课堂计时器、小组活动计分（不持久化，仅课堂展示）

### B5 事件台账
**目的**：轻量事件留痕（不做积分），是评语与家校沟通的素材库。

字段：日期、学生、类型（表扬/违纪/冲突/意外/其他）、类别标签（自定义，如"上课说话""助人为乐""体育受伤"）、描述、处理方式、是否通知家长、跟进事项、严重度（低/中/高，仅违纪冲突用）。

操作流程：列表按类型/学生/日期筛选 → 点"+"登记（支持批量选多个学生同事件）→ 可标记"已处理"。

细节与边界：
- 冲突事件：自动提醒"建议 24h 内联系双方家长"（弹窗提示）
- 意外（受伤/生病）：必须登记处理过程（送医务室/通知家长/就医），形成安全台账
- 学期汇总：按学生生成"事件清单"，供评语与家长会谈使用
- 打印：`谈话/事件记录存档`（A4，含处理过程）

## C. 学习与成绩

### C1 考试管理
字段：考试名（如"期中考试"）、类型（单元测/月考/期中/期末）、日期、备注。

细节与边界：
- 每次考试按班设置科目及满分：班主任班全科；任教班只有语文
- 满分灵活：如语文 120、数学 120、英语 100、政治 70、历史 70、地理 60、生物 60
- 一个"考试"可覆盖多个班（同一次期中考试，班主任班与任教班各自录分）

### C2 成绩录入与分析（可视化）
**录入**：
- 矩阵式：行=学生、列=科目；Tab 键跳格；支持从 Excel 复制整列粘贴
- **一键导入**：从学校平台/智学网导出表直接导入（见 H4 导入中心，成绩宽表/长表）
- 缺考/缓考标记（不参与统计）；修改留痕（updated_at + 备注）
- 可选：语文分项（基础/阅读/作文）录入 → 分项得分率分析（v1.5）

**分析（完整规格见 `docs/03-成绩分析专项设计.md`）**：
- **10 张可视化图表**：分数段分布柱状图、各科均分对比、优秀率/及格率对比、班级总均分走势、
  各科走势折线、分数段堆叠图、学生雷达图（偏科一眼看清）、个人走势（均分+排名双轴）、
  进步榜/退步榜、任教班语文双班对比
- **7 张统计表**：成绩总表（矩阵可排序）、各科统计表（含中位数/标准差）、分数段交叉表、
  个人明细、进退步对比表、偏科预警表、**临界生名单**（及格线/优秀线上下 10 分，阈值可配）
- **图表联动**：点柱状图某分数段 → 下方表格自动筛选该段学生；悬停显示数值
- **自动分析报告**：一次考试结束一键生成"质量分析"（文字总结+图表+表格），导出 PDF/Word，
  可直接交学校或家长会使用
- **隐私**：排名默认隐藏、图表默认匿名（学号后两位），可切换显示姓名；成绩条不带排名

**打印/导出**：成绩条（家长会发，无排名）；每张图表导出 PNG（2x DPI）；每张表导出 Excel；分析报告 PDF/Word。

### C3 学习小组与帮扶
- 小组划分：行政小组（与值日组可同可不同）、学习小组（异质分组：好中差搭配）
- 活动 PK：课堂工具包的"小组计分"（不持久化不排名）与"小组活动记录"（如知识竞赛结果）
- 结对帮扶：名单（师傅→徒弟）、帮扶记录（每周一次登记：内容/效果）

## D. 德育与成长

### D1 谈心谈话
字段：日期、学生、地点、时长（分钟）、起因（主动约谈/事件触发/家长要求/例行）、
主题、谈话要点、学生反馈、跟进事项、下次跟进日期。

细节与边界：
- 看板提醒：`follow_up_date` 到期未处理 → 今日看板标红
- 统计：本学期每生谈话次数；重点关注学生（红）建议每 2 周至少 1 次（看板提示缺口）
- 打印：`谈话记录存档`（含时间线，家长会或德育处备查）

### D2 重点关注学生（红黄绿台账）
- 分级：`红`（心理危机/行为严重问题，需持续跟进并考虑上报）/ `黄`（需观察）/ `绿`（关注中已好转，可降级）
- 记录：关注原因、开始日期、级别变更历史、负责跟进事项
- 节奏建议：红=每周联系 1 次（家长+学生）、黄=每 2 周 1 次、绿=每月 1 次；超期看板提醒
- 隐私：该页为"私密台账"，列表默认模糊化姓名（点开展开），导出默认排除

### D3 成长档案（时间线）
**目的**：数据一体化的最终产出 —— 每生一页，聚合所有模块记录。

时间线内容（按时间倒序）：考勤异常、作业未交/优秀、事件（表扬/违纪/冲突/意外）、
谈话、家校联系、成绩（每次考试各科）、荣誉、活动参与、班委任职。

细节与边界：
- 页面顶部：学生信息卡（照片/学号/标签/红黄绿级别）
- 筛选：按类型、按学期
- 导出：`成长手册`（PDF，按学期分章，用于家长会展示或毕业归档）
- 隐私：成长手册导出时可选择"排除敏感记录"（如心理相关）

## E. 家校沟通

### E1 联系记录
字段：日期、方式（电话/微信/面谈/家访）、沟通对象（爸爸/妈妈/爷爷/奶奶/其他）、
事由、沟通要点、结果、下次联系日期、是否解决。

细节与边界：
- 提醒规则（看板）：
  - 红级学生：超 2 周未联系家长 → 提醒
  - 黄级学生：超 1 月未联系 → 提醒
  - 连续未交作业/考勤异常学生：建议尽快联系
- 家访单独视图：家访计划列表、家访记录（与联系记录同表，方式=家访）
- 打印：`家访记录存档`

### E2 家长会
字段：时间、主题、议程、要点记录、到场情况。

细节与边界：
- 签到表打印：按学生列表生成，家长签名栏

### E3 通知留痕

细节与边界：
- **不自动发送**（遵守学校群规，微信外发由老师手动操作）；系统只做记录与模板
- 常用通知模板库（如"缴费通知""放假通知""收作业通知"）可复用编辑

## G. 期末与总结

### G1 学期评语
**目的**：解决学期末评语难题 —— 素材库 + 记录聚合草稿 + 五维评价 + 批量打印。

流程：
1. 选择学期 → 系统聚合每生该学期记录：表扬次数/类型、违纪情况、谈话主题、考勤、
   成绩趋势（进步科目）、活动与荣誉
2. 生成草稿：模板句组装（优点句 + 进步句 + 期望句 + 鼓励句），老师编辑定稿
3. 五维评价（每维一个等级 + 一句评语）：品德表现 / 学业水平 / 运动健康 / 劳动实践 / 审美素养
4. 操行等级：优 / 良 / 中 / 待合格（参考违纪严重度，老师确认）

评语库（素材管理）：
- 分类：优点 / 期望 / 鼓励 / 具体事例；支持收藏自己写的好句子
- 插入：编辑评语时可从素材库点选插入

细节与边界：
- 每生一条，`comment_draft`（草稿）与 `comment_final`（定稿）分离，可对比
- 编辑历史记录（谁改了什么——单用户场景记录时间线即可）
- 打印：`操行评定表`（学校表格版式，全班批量打印）

### G2 学期报告
一键生成班级学期总结：出勤汇总、成绩走势、事件统计、荣誉清单、活动回顾、
重点关注学生跟进情况。用途：家长会、德育处汇报、个人工作小结存档。

### G3 学期归档与开新班
- 学期结束：当前班级 → 归档（全部只读）
- 新学期：创建新班 → 复制模板（考勤节点/值日任务/科目/评语素材/通知模板）
- 学生迁移：新班学生从旧班"一键复制"（可勾选排除敏感字段：健康备注、重点关注）
- 毕业：整班归档 + 成长手册导出

|---|---|---|
| 座位表（带照片/不带照片） | 贴讲台/交年级组 | — |
| 座位图 PNG（2x/3x DPI） | 发家长群/教室大屏 | 可脱敏仅姓名 |

技术：浏览器打印（@media print CSS），每表格一套 A4 版式；手机/iPad 可存 PDF。

### H4 导入中心（一键导入，解析正确）
**目的**：把学校系统/教务表一键导入系统。核心承诺：**解析正确、不丢数据、可预览、可纠错、可重复导入**。

**支持的导入类型（v1）**：
| 类型 | 模板核心字段 | 唯一键（幂等 upsert） | 典型来源 |
|---|---|---|---|
| 学生名单 | 学号、姓名、性别、生日、监护人1/2 电话与关系、住址、小学、备注 | 班内学号 | 学校学籍表/教务 Excel |
| 成绩（宽表） | 学号、姓名、[各科分数列] | 考试 + 学号 + 科目 | 智学网/学校平台导出 |
| 成绩（长表） | 学号、姓名、科目、分数、缺考 | 考试 + 学号 + 科目 | 自建表 |
| 座位表 | 行、列、学号/姓名 | 班内学号 | 教务排座表/上届迁移 |
| 家长信息更新 | 学号、姓名、监护人1/2 电话、关系 | 班内学号（**只更新非空列**） | 学校更新名单 |
| 考勤（可选） | 日期、学号、状态 | 日期 + 学号 + 节点 | 学校考勤导出 |

**通用导入流程（6 步）**：
1. 下载标准模板（xlsx，含表头说明行与示例行）
2. 上传文件（.xlsx / .xls / .csv，拖拽上传，≤10MB）
3. **自动识别表头与列映射**（同义词词典，见下；映射可手工修正）
4. **预览**：分页展示解析结果，自动标红异常行（行号 + 字段 + 原因）
5. **校验报告**：成功 N 行 / 错误 M 行，逐条列出
6. **提交策略**二选一：全部通过才提交（事务）；或跳过错误行提交正确行（提交后导出错误报告 CSV）

**解析引擎细节（"解析正确"的保障）**：
- **表头同义词词典**：
  `学号 ↔ 学籍号 ↔ 编号 ↔ 学生编号`；
  `姓名 ↔ 学生姓名 ↔ 名字`；
  `性别 ↔ 男女性别`；
  `生日 ↔ 出生日期 ↔ 出生年月`；
  `监护人电话 ↔ 家长电话 ↔ 父亲电话 ↔ 母亲电话`；
  分数列 = 科目名精确匹配（语文/数学/英语…，忽略表头空格与换行）
- **多表头支持**：学校导出表常在首行写标题（如"XX中学期中成绩表"）。检测规则：若第 1 行含"学号/姓名"关键字则视为表头，否则自动跳过前 N 行找到表头行
- **类型转换**：
  - 学号/编号：**按文本解析，保留前导零**（`001` 不变成 `1`）；科学计数法还原（`1.23E+5` → `123000`）
  - 日期：Excel 序列号（如 `45292`）与文本（`2025/9/1`、`2025-09-01`、`2025年9月1日`）统一转 date
  - 性别：`男/女/1/0/M/F/男生/女生` → 归一为 `男/女`
  - 分数：数值校验（0 ~ 该科满分），文本"缺考/请假/空" → 缺考标记
  - 手机号：11 位校验，兼容 `138-1234-5678` 与空格
- **编码与杂项**：CSV 自动识别 UTF-8 / GBK（含 BOM 处理）；跳过全空行；合并单元格取左上角值；公式单元格取计算值
- **幂等性**：按唯一键 upsert —— 重复导入不产生重复数据；成绩导入对"已有记录"提供选项：覆盖 / 跳过 / 全部中止
- **导入日志**：每次导入写入 `import_logs`（类型、文件名、成功/失败数、错误明细 JSONB），可查"上次导入是否成功、哪些行失败"

**导出（保留）**：全部数据 JSON（备份用）；学生名单/考勤/成绩/事件/评语 Excel；评语批量 Word/CSV；座位图 PNG（见 A3）。

### H5 备份、隐私与审计
- **备份**：每周备份提醒（默认开）；一键全量导出 JSON（含所有班级、所有学期）；
  **加密备份**（导出时设密码，Web Crypto AES-GCM，生成 `.dshbak` 文件）；恢复需密码（v1.5）
- **隐私显示**：列表手机号打码（默认开）、重点关注页模糊化（默认开）、导出脱敏（默认开）
- **审计日志**：登录、导出、导入、敏感页查看、一键隐藏等操作写入 `audit_logs`（**只追加，不可改删**），
  安全中心可查"最近登录与操作记录"（异地登录自查）
- **数据保留**：软删除 30 天回收站；"清空回收站"= 彻底物理删除（二次确认）；转学生档案永久保留
- **RLS**：所有表行级安全（仅 owner），见 schema.sql；完整安全设计见 `docs/04-数据与使用安全设计.md`

### H6 安全中心（使用安全）
**账号安全**：
- 强密码（≥10 位混合字符）+ **MFA（TOTP 二步验证，强烈建议开启）**
- 最近登录记录与登录设备列表；一键"退出所有设备"；公开注册已关闭（部署时设置）

**防偷看（手机/教室场景，班主任特有需求）**：
- **应用锁**：4-6 位 PIN（存设备本地）；空闲锁定 5/15/30 分钟可选（默认 15）；重新打开需 PIN
- **敏感页二次验证**：重点关注台账、心理/敏感事件、成绩排名、完整手机号 → 进入需 PIN
- **一键隐藏**：手机端悬浮按钮（长按触发），瞬间切到伪装页（空白/天气样式），恢复需 PIN，触发留审计
- **水印**：敏感页面叠加半透明水印（"张老师 · 日期 · 内部资料"），导出 PDF/PNG 同步加水印 —— 截图外泄可溯源

**误操作保护**：
- 高危操作二次确认：批量删除、清空、覆盖导入、清空回收站
- 覆盖导入前自动备份被覆盖数据；撤销/回收站兜底

**失窃应急**：设备丢失 → 立即"退出所有设备" + 重置密码 + 确认 MFA 与最近备份（详见 04 文档 §3.7）
